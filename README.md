# Личная страница разработчика

Личная страница разработчика с рабочей формой обратной связи, серверной частью и небольшим примером использования ИИ. Визуально это самостоятельная черно-бело-серая страница с крупной типографикой и портретом в первом экране.

## Стек

- Frontend: TypeScript, HTML, SCSS, Vite
- Backend: Node.js, Express, Zod
- Email: Nodemailer через SMTP
- ИИ: OpenAI API через сервер, без ключа используется заранее подготовленный текст

## Архитектура

```text
apps/
  frontend/
    public/
    src/
      api/
      components/
      data/
      features/
      styles/
      types/
  backend/
    src/
      config/
      routes/
      schemas/
      services/
      utils/
```

Frontend и backend лежат отдельно. Интерфейс собран из небольших компонентов, логика формы и блока с ИИ вынесена в `features`, запросы к API лежат в `api`, данные профиля в `data`. На backend отдельно лежат роуты, сервисы, схемы валидации, конфиг окружения и утилиты.

На странице отдельно вынесен стек, чтобы его можно было быстро прочитать. В кейсах указаны реальные части этого проекта: страница, форма обратной связи и блок с ИИ.

## Запуск

```bash
npm install
npm run dev
```

Frontend откроется на `http://localhost:5173`, API работает на `http://localhost:5174`.

Проверка сборки:

```bash
npm run typecheck
npm run build
npm run start
```

После `npm run start` Express отдает API и собранный frontend из одного Node.js приложения.

## Настройки окружения

Создайте `.env` по примеру `.env.example`.

Для локального демо можно оставить:

```env
MAIL_DEV_MODE=true
```

В этом режиме форма возвращает успешный ответ, а письма владельцу и пользователю выводятся в консоль backend-сервера.

Для реальной отправки писем:

```env
MAIL_DEV_MODE=false
SMTP_HOST=smtp.example.com
SMTP_PORT=465
SMTP_SECURE=true
SMTP_USER=user@example.com
SMTP_PASS=change-me
MAIL_FROM="Руслан Тимергалиев <user@example.com>"
OWNER_EMAIL=owner@example.com
```

Для блока с ИИ:

```env
OPENAI_API_KEY=sk-...
OPENAI_MODEL=gpt-4o-mini
```

Если `OPENAI_API_KEY` не задан, `/api/ai-summary` возвращает заранее подготовленный текст, чтобы демо не ломалось.

## Как реализована форма

Форма находится на главной странице и содержит поля:

- имя
- телефон
- email
- комментарий

На frontend есть проверка полей, состояние отправки, сообщение об успехе и сообщение об ошибке. На backend данные повторно проверяются через `zod`, затем `Nodemailer` отправляет два письма:

- владельцу сайта на `OWNER_EMAIL`
- копию пользователю на email из формы

При ошибке SMTP сервер возвращает понятный `502` JSON-ответ, который frontend показывает пользователю.

## Интеграция с ИИ

На странице есть блок с коротким описанием профиля. Кнопка обращается к `/api/ai-summary`.

- Если задан `OPENAI_API_KEY`, backend запрашивает текст через OpenAI API.
- Если ключа нет или API временно недоступно, возвращается заранее подготовленный текст.

Запрос к OpenAI идет только с backend, ключ не попадает в браузер.

## Деплой

Проект можно деплоить как Node.js сервис на Render, Railway, Fly.io или похожую платформу.

Команды:

```bash
npm install
npm run build
npm run start
```

Для production нужно задать переменные окружения из раздела настроек и указать `MAIL_DEV_MODE=false`.
