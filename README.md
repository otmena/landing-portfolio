# Личная страница разработчика

## Как запустить проект

```bash
npm install
npm run dev
```

Frontend: `http://localhost:5173`

Backend/API: `http://localhost:5174`

Проверка сборки:

```bash
npm run typecheck
npm run build
npm run start
```

## Какой стек использован

- HTML
- SCSS
- TypeScript
- Vite
- Node.js
- Express
- Zod
- Nodemailer
- OpenAI API

## Как реализована форма

Форма содержит поля:

- имя
- телефон
- email
- комментарий

На frontend сделаны проверка полей, состояние отправки, сообщение об успешной отправке и сообщение об ошибке.

На backend есть endpoint `POST /api/contact`. Данные повторно проверяются через `zod`. После успешной проверки `Nodemailer` отправляет письмо владельцу сайта и копию пользователю на email из формы.

Если отправка не удалась, backend возвращает ошибку, а frontend показывает ее пользователю.
